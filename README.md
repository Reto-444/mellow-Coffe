============================================================
  Mellow Coffee — одностраничный сайт кофейни
============================================================

Демонстрационный проект для портфолио веб-разработчика.
Небольшой, но аккуратный лендинг современной кофейни
с минималистичным дизайном и плавными интерактивными
эффектами.

------------------------------------------------------------
  Стек технологий
------------------------------------------------------------
- HTML5
- CSS3 (переменные, flexbox, grid, медиазапросы)
- Vanilla JavaScript (без библиотек и фреймворков)
- Шрифты Google Fonts: Fraunces, Inter

Проект полностью статический. Не требует сборки, npm,
backend или базы данных. Работает на GitHub Pages.

------------------------------------------------------------
  Структура проекта
------------------------------------------------------------
mellow-coffee/
├── index.html      — разметка страницы
├── style.css       — все стили, переменные, адаптивность
└── script.js       — мобильное меню, анимации, прокрутка

------------------------------------------------------------
  Быстрый старт
------------------------------------------------------------
1. Скачайте или склонируйте папку с проектом.
2. Откройте файл index.html в любом современном браузере.
3. Готово — сайт работает локально.

Для разработки можно использовать любой локальный сервер,
например:
  npx serve .
или
  python -m http.server

------------------------------------------------------------
  Публикация на GitHub Pages
------------------------------------------------------------
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него три файла: index.html, style.css, script.js.
3. Перейдите в Settings → Pages.
4. В разделе Source выберите ветку main и папку / (root).
5. Нажмите Save.
6. Через 1–2 минуты сайт будет доступен по адресу:
   https://<ваш-логин>.github.io/<имя-репозитория>/

------------------------------------------------------------
  Как настроить под себя
------------------------------------------------------------
— Цвета и размеры:
  Все основные цвета, шрифты, радиусы и отступы вынесены
  в CSS-переменные в начале файла style.css (блок :root).
  Меняйте значения — сайт обновится автоматически.

— Тексты:
  Редактируются прямо в index.html. Название кофейни,
  заголовки, описания, цены, адрес и время работы.

— Изображения:
  Используются прямые ссылки на Unsplash. Вы можете
  заменить их на свои, изменив атрибут src у тегов <img>.
  Если изображение не загрузится, сработает запасной фон
  (градиент с иконкой кофе).

------------------------------------------------------------
  Реализованная интерактивность
------------------------------------------------------------
- Плавная прокрутка к секциям (CSS scroll-behavior + JS).
- Мобильное меню: открытие/закрытие по клику на бургер,
  закрытие по Escape, клику по ссылке или при ресайзе.
- Появление блоков при прокрутке (IntersectionObserver).
- Подсветка активного пункта меню в шапке.
- Эффекты наведения на кнопки и карточки меню.
- Футер: автоматическая подстановка текущего года.

------------------------------------------------------------
  Адаптивность
------------------------------------------------------------
Сайт корректно отображается на:
- широких мониторах (от 1200px)
- ноутбуках (1024–1199px)
- планшетах (768–1023px)
- смартфонах (от 320px)

Точки перелома: 1024px, 900px, 560px, 360px.
Горизонтальная прокрутка отсутствует.

------------------------------------------------------------
  Особенности
------------------------------------------------------------
- Семантическая разметка HTML5.
- Доступность: skip-link, aria-атрибуты, focus-visible.
- Анимации отключаются при prefers-reduced-motion.
- Нет inline-стилей (кроме необходимых случаев).
- Код структурирован и снабжён комментариями.
